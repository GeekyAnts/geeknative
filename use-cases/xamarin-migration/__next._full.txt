Apps built with them no longer get updates for new iOS and Android SDKs. Microsoft's own path is .NET MAUI. Many teams take the move as a chance to rethink the stack instead.</p>
<p>If you want native apps, geeknative gives you a direct route. A coding agent builds the app in SwiftUI for iOS, Jetpack Compose for Android and React for the web, from one spec that you write from your current app.</p>
<h2 id="your-options">Your options<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#your-options">#</a></h2>

<p>There is no wrong answer. If your team is strong in .NET and the app is mostly forms and data, MAUI may be the shortest path. If native look, feel and platform features matter, a native rebuild is worth it, and a coding agent makes it affordable.</p>
<h2 id="how-the-rebuild-works">How the rebuild works<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#how-the-rebuild-works">#</a></h2>
<ol>
<li><strong>Inventory the app.</strong> List every screen and feature. Ask your agent to turn that into PRODUCT.md and <code>spec/navigation.md</code>.</li>
<li><strong>Write specs from current behavior.</strong> One spec per feature in <code>spec/features/</code>, with numbered acceptance criteria. Existing test plans are a good source.</li>
<li><strong>Move the brand and copy.</strong> Colors and type go in <code>contracts/tokens.json</code>. Strings go in <code>contracts/strings/</code>, including other locales. <code>make gen</code> compiles them into every app.</li>
<li><strong>Keep your backend.</strong> Implement each feature's repository against your existing services.</li>
<li><strong>Build feature by feature.</strong> Each feature goes through all three apps before the next starts. <code>make parity</code> shows coverage per platform.</li>
</ol>
<h2 id="what-you-end-up-with">What you end up with<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#what-you-end-up-with">#</a></h2>
<ul>
<li>An iOS app in SwiftUI with <code>@Observable</code> view models, for iOS 17 and later.</li>
<li>An Android app in Kotlin and Jetpack Compose with Material 3, for Android 7.0 and later.</li>
<li>A web app in React 19 on TanStack Start with Tailwind CSS v4.</li>
<li>A spec and contracts your team keeps, so the next migration is never this hard.</li>
</ul>
<h2 id="what-to-know-first">What to know first<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#what-to-know-first">#</a></h2>
<ul>
<li>There is no automated converter. The agent builds new apps from specs, not from C# code.</li>
<li>Check the minimum versions against your users. Xamarin apps often supported older devices.</li>
<li>geeknative is at version 0.1. Upgrades for existing projects are on the <a href="/geeknative/docs/project/roadmap/">roadmap</a>.</li>
</ul>
