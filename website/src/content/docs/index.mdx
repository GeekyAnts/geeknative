## Start in a minute

```sh
npm create geeknative@latest my-app -- --name "My App" --id com.acme.myapp
cd my-app
make doctor   # checks Xcode, the Android SDK, Java and Node; FIX=1 installs what's missing
make check    # builds and tests all three apps
```

Then open the folder in your coding agent and describe what you want to build. The CLI is on npm as [geeknative](https://www.npmjs.com/package/geeknative).

The apps share no code. Each one is written in its platform's own language and follows its own conventions, so it looks and behaves the way people on that platform expect.

## How it works

<CardGrid>
  <Card title="One source of truth" icon="open-book">
    PRODUCT.md says what the app is, DESIGN.md how it looks, and `spec/features/` how each feature behaves, with numbered acceptance criteria.
  </Card>
  <Card title="Contracts compiled into every app" icon="setting">
    `contracts/` holds the app identity, design tokens, copy and icons. `make gen` turns them into Swift, Kotlin, Android resources, TypeScript and Tailwind, so they can't drift.
  </Card>
  <Card title="Same architecture, same names" icon="list-format">
    A feature `notes` is `NotesScreen`, `NotesViewModel` and `NotesRepository` on every platform. One search finds all three.
  </Card>
  <Card title="Checks for every app" icon="approve-check">
    `make check` builds and tests all three apps. Tests carry acceptance criteria IDs, and `make parity` shows what each platform covers.
  </Card>
</CardGrid>

## What happens when you prompt

<Steps>

1. You describe what you want in plain words: "Add a notes list where I can add and delete notes."

2. The agent states how it reads the request, in one line, so you can correct it early:
   `Feature: notes list → spec/features/notes.md, strings · iOS, Android, Web`

3. It writes `spec/features/notes.md`, with acceptance criteria numbered `AC-notes-1`, `AC-notes-2`, and so on.

4. It adds the new copy to `contracts/strings/en.json` and runs `make gen`.

5. It builds the feature in SwiftUI, Compose and React. Agents that support sub-agents do the three apps in parallel.

6. It runs `make check` until every app builds and passes its tests, records each platform's status, runs `make parity`, and reports one line per platform.

</Steps>
