<h2 id="managed-blocks">Managed blocks<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#managed-blocks">#</a></h2>
<p>AGENTS.md files mix framework rules and your rules. The framework's part sits between markers:</p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="md"><code><span class="line"><span style="color:#A3A09C;font-style:italic">&#x3C;!-- geeknative:begin (managed by geeknative: replaced on upgrade. <span class="line"><span style="color:#686664;font-weight:bold">#</span><span style="color:#0B0B0B;font-weight:bold"> How to work in this repo</span></span>
<span class="line"><span style="color:#0B0B0B">...</span></span>
<span class="line"><span style="color:#A3A09C;font-style:italic">&#x3C;!-- geeknative:end --></span></span>
<span class="line"></span>
<span class="line"><span style="color:#686664;font-weight:bold">##</span><span style="color:#0B0B0B;font-weight:bold"> Project rules</span></span>
<span class="line"></span>
<span class="line"><span style="color:#686664">-</span><span style="color:#0B0B0B"> Brand voice is playful.</span></span>
<span class="line"><span style="color:#686664">-</span><span style="color:#0B0B0B"> No bottom sheets on iOS.</span></span></code></pre>

<p>The same applies to <code>apps/ios/AGENTS.md</code>, <code>apps/android/AGENTS.md</code>, <code>apps/web/AGENTS.md</code> and the Claude Code section of the root <code>CLAUDE.md</code>.</p>

<h2 id="upgrades">Upgrades<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#upgrades">#</a></h2>
<p><code>geeknative upgrade</code> is planned, not built yet; see the <a href="/geeknative/docs/project/roadmap/">roadmap</a>. The lockfile is what will make it safe:</p>
<ul>
<li>framework files you never touched (their hash still matches) get replaced;</li>
<li>framework files you edited get a three-way merge with the new version, with conflicts listed;</li>
<li>your files are never touched, except by explicit migrations;</li>
<li>generated files are rebuilt by <code>make gen</code>.</li>
</ul>
<p>Because <code>create</code> already writes the lockfile, projects created today can be upgraded when the command ships.</p>
<h2 id="generated-files">Generated files<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#generated-files">#</a></h2>
