<h2 id="instructions">Instructions<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#instructions">#</a></h2>
<p>The project has one-line <code>CLAUDE.md</code> files next to each <code>AGENTS.md</code> (at the root and in <code>apps/ios</code>, <code>apps/android</code> and <code>apps/web</code>) that import it:</p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="md"><code><span class="line"><span style="color:#0B0B0B">@AGENTS.md</span></span></code></pre>
<p>Recent versions of Claude Code read AGENTS.md on their own, but only when the project has no CLAUDE.md. The import keeps the instructions loading either way, including when a developer has a personal <code>CLAUDE.local.md</code>. The per-app files load when Claude starts working on files in that app.</p>
<p>The root CLAUDE.md also has a Claude-specific section, managed by geeknative:</p>
<ul>
<li>When a change touches more than one app, Claude hands the platform work to three subagents in parallel and stays the lead. The lead owns <code>spec/</code>, <code>contracts/</code>, PRODUCT.md and DESIGN.md.</li>
<li>A hook regenerates code whenever a file in <code>contracts/</code> is edited.</li>
<li>A stop hook reminds Claude once if a turn changed some apps but not the others.</li>
</ul>
<h2 id="platform-subagents">Platform subagents<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#platform-subagents">#</a></h2>

<p>Each one gets a brief from the lead (the spec path, the acceptance criteria IDs and what changed in <code>contracts/</code>) and:</p>
<ol>
<li>reads the spec and follows the existing Settings feature as the pattern;</li>
<li>implements from the spec, without porting code from the other apps;</li>
<li>edits only its own app, never <code>spec/</code>, <code>contracts/</code>, PRODUCT.md, DESIGN.md or generated files, and reports spec gaps instead of guessing;</li>
<li>names tests after acceptance criteria;</li>
<li>runs its platform's check until it passes;</li>
<li>reports the files it changed, the criteria its tests cover, the check result, and any gaps.</li>
</ol>
<h2 id="hooks">Hooks<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#hooks">#</a></h2>
<p><code>.claude/settings.json</code> registers three hooks. The scripts live in <code>.geeknative/hooks/</code> and run with Node.</p>
<div class="table-wrap"><table>
<thead>
<tr>
<th>Event</th>
<th>Script</th>
<th>What it does</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>PostToolUse</code> on Edit, Write and MultiEdit</td>
<td><code>after-edit.mjs</code></td>
<td>If the edited file is in <code>contracts/</code>, runs <code>geeknative gen</code> right away. If the contract is invalid, it reports the error to Claude so it can fix the contract.</td>
</tr>
<tr>
<td><code>SubagentStart</code> for each platform subagent</td>
<td><code>subagent-context.mjs &#x3C;platform></code></td>
<td>Adds that platform's <code>apps/&#x3C;platform>/AGENTS.md</code> to the subagent's context when it starts.</td>
</tr>
<tr>
<td><code>Stop</code></td>
<td><code>parity-guard.mjs</code></td>
<td>If the uncommitted changes touch some apps but not the others, it asks Claude once to finish the other apps or explain why the change is platform-specific.</td>
</tr>
</tbody>
</table></div>
<p>The stop hook ignores generated files and agent docs, and remembers the set of changes it already flagged (in <code>.git/geeknative-parity-guard</code>), so it reminds once and then lets Claude finish. It does nothing outside a git repository or before the first commit.</p>
<h2 id="permissions">Permissions<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#permissions">#</a></h2>
<p><code>.claude/settings.json</code> allows the commands Claude needs for its build and test loop without asking each time:</p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="json"><code><span class="line"><span style="color:#9F0310">"allow"</span><span style="color:#0B0B0B">: </span><span style="color:#686664">[</span></span>

<span class="line"><span style="color:#9F0310">  "Bash(npx geeknative *)"</span><span style="color:#686664">,</span></span>
<span class="line"><span style="color:#9F0310">  "Bash(./node_modules/.bin/geeknative *)"</span><span style="color:#686664">,</span></span>
<span class="line"><span style="color:#9F0310">  "Bash(npm run *)"</span><span style="color:#686664">,</span></span>
<span class="line"><span style="color:#9F0310">  "Bash(xcodebuild *)"</span><span style="color:#686664">,</span></span>

<p>Claude Code applies project permissions after you accept the workspace trust prompt for the folder. Your own permissions go in <code>.claude/settings.local.json</code>.</p>
<h2 id="tips">Tips<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#tips">#</a></h2>

<li>If the stop hook flags a change you meant for one platform only, tell Claude so; it records the difference in the spec's Platform notes.</li>
