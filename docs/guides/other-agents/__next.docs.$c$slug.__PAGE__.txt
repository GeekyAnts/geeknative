<h2 id="agents-that-read-agentsmd">Agents that read AGENTS.md<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#agents-that-read-agentsmd">#</a></h2>
<p>Codex, Cursor, the GitHub Copilot coding agent and many others read <code>AGENTS.md</code> at the project root. Open the project folder and prompt as usual.</p>
<p>Each app also has its own <code>AGENTS.md</code> with its conventions:</p>

<p>Some agents load nested AGENTS.md files on their own and some don't, so the root file also tells the agent to read <code>apps/&#x3C;platform>/AGENTS.md</code> before editing in that folder.</p>

<h2 id="agents-without-sub-agents">Agents without sub-agents<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#agents-without-sub-agents">#</a></h2>
<p>The loop in AGENTS.md works with or without sub-agents. If your agent can run sub-agents in parallel, it gives each platform its own. Otherwise it does the platforms one after another. Either way, the request isn't done until all three apps do it (or the spec marks the difference).</p>
<h2 id="whats-claude-specific">What's Claude-specific<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#whats-claude-specific">#</a></h2>
<p>The hooks and subagents in <code>.claude/</code> only run in Claude Code. With other agents:</p>
<ul>
<li>AGENTS.md tells the agent to run <code>make gen</code> after editing <code>contracts/</code>. The <a href="/geeknative/docs/guides/claude-code/">Claude Code</a> hook does that automatically.</li>
<li>The parity reminder doesn't run, but <code>make parity</code> and the agent's per-platform report show the same information.</li>
