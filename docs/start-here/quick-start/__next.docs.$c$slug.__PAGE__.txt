<p><strong>Create a project.</strong></p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="shell"><code><span class="line"><span style="color:#0B0B0B;font-weight:bold">npm</span><span style="color:#0B0B0B"> create</span><span style="color:#0B0B0B"> geeknative@latest</span><span style="color:#0B0B0B"> my-app</span><span style="color:#686664"> --</span><span style="color:#686664"> --name</span><span style="color:#9F0310"> "My App"</span><span style="color:#686664"> --id</span><span style="color:#0B0B0B"> com.acme.myapp</span></span></code></pre>
<p><code>--name</code> is the display name and <code>--id</code> is the bundle ID on iOS and the application ID on Android. Both are written to <code>contracts/app.json</code>, the only place they live. Without them, the name comes from the folder (<code>my-app</code> becomes "My App") and the ID is <code>com.example.myapp</code>.</p>
<p>The command copies the template, generates the platform code, installs dependencies with npm and makes a first git commit. Add <code>--no-install</code> or <code>--no-git</code> to skip those steps.</p>
<p>You can also run the CLI directly: <code>npx geeknative@latest create my-app --name "My App" --id com.acme.myapp</code>.</p>
</li>
<li>
<p><strong>Check your toolchains.</strong></p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="shell"><code><span class="line"><span style="color:#0B0B0B;font-weight:bold">cd</span><span style="color:#0B0B0B"> my-app</span></span>
<span class="line"><span style="color:#0B0B0B;font-weight:bold">make</span><span style="color:#0B0B0B"> doctor</span></span></code></pre>
<p><code>make doctor</code> checks Node, the npm dependencies, the contracts, Xcode and an iPhone simulator, Java, and the Android SDK. <code>make doctor FIX=1</code> installs what it safely can: npm dependencies and the Android API level the app compiles against. See <a href="/geeknative/docs/start-here/requirements/">Requirements</a>.</p>
</li>
<li>
<p><strong>Build and test all three apps.</strong></p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="shell"><code><span class="line"><span style="color:#0B0B0B;font-weight:bold">make</span><span style="color:#0B0B0B"> check</span></span></code></pre>
<p>This validates the contracts, then builds and tests the iOS, Android and web apps, printing one line per app. Full logs go to <code>.geeknative/logs/</code>.</p>
<aside class="callout callout-note" data-label="Note"><p>The first Android build downloads Gradle, JDK 21 and the app's dependencies, so it can take several minutes. Later builds take seconds.</p></aside>
</li>
<li>
<p><strong>Run the apps.</strong></p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="shell"><code><span class="line"><span style="color:#0B0B0B;font-weight:bold">make</span><span style="color:#0B0B0B"> run-ios</span><span style="color:#A3A09C;font-style:italic">       # builds, installs and launches in an iPhone simulator</span></span>
<span class="line"><span style="color:#0B0B0B;font-weight:bold">make</span><span style="color:#0B0B0B"> run-android</span><span style="color:#A3A09C;font-style:italic">   # installs and launches on a connected device or an emulator</span></span>
<span class="line"><span style="color:#0B0B0B;font-weight:bold">make</span><span style="color:#0B0B0B"> run-web</span><span style="color:#A3A09C;font-style:italic">       # starts the dev server at http://localhost:3000</span></span></code></pre>
</li>
<li>
<p><strong>Give your agent its first prompt.</strong></p>
<p>Open the folder in Claude Code, Codex, Cursor, Gemini CLI or another agent that reads AGENTS.md, and describe your app:</p>
<blockquote>
<p>Build a habit tracker. People create habits, check them off each day, and see their current streak.</p>
</blockquote>
<p>The agent fills in PRODUCT.md and DESIGN.md, writes a spec for each feature, and builds them one at a time on all three platforms. See <a href="/geeknative/docs/guides/idea-to-three-apps/">From idea to three apps</a>.</p>
</li>
</ol>
<h2 id="run-make-to-see-every-command">Run <code>make</code> to see every command<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#run-make-to-see-every-command">#</a></h2>

<span class="line"><span>  make doctor           Check toolchains (FIX=1 installs what it can)</span></span>
<span class="line"><span>  make gen              Regenerate app code from contracts/</span></span>
<span class="line"><span>  make check            Validate contracts, then build and test all three apps</span></span>
<span class="line"><span>  make check-contracts  Validate contracts and check generated code is current</span></span>

<span class="line"><span>  make run-ios          Build and launch the iOS app in a simulator</span></span>
<span class="line"><span>  make run-android      Build and launch the Android app on an emulator or device</span></span>
<span class="line"><span>  make run-web          Start the web dev server</span></span></code></pre>
