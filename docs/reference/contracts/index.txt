<p><strong>Names</strong> are camelCase letters and digits starting lowercase, and can't be reserved words in Swift, Kotlin or TypeScript (like <code>default</code> or <code>class</code>).</p>
<p><strong>Colors</strong> are <code>#RRGGBB</code> or <code>#RRGGBBAA</code>. <code>dark</code> is optional and defaults to <code>light</code>. These colors are required: <code>background</code>, <code>onBackground</code>, <code>surface</code>, <code>onSurface</code>, <code>surfaceVariant</code>, <code>onSurfaceVariant</code>, <code>primary</code>, <code>onPrimary</code>, <code>outline</code>, <code>error</code> and <code>onError</code>. You can add more.</p>
<p><strong>Spacing, radius, icon and size</strong> values are numbers of points (iOS), dp (Android) or pixels (web). <code>size</code> is optional and holds fixed sizes of things, like touch targets: its names can't repeat a spacing name or start with <code>icon</code>, because on the web they all share Tailwind's spacing scale. A radius of 9999 or more is fully rounded on the web. Icon sizes are the sizes icons are drawn at in content.</p>

<span class="line"><span style="color:#686664">}</span></span></code></pre>
<div class="table-wrap"><table>

<tr>
<th>Field</th>
<th>Rule</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>environments</code></td>

<tr>

<h3 id="choosing-the-environment">Choosing the environment<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#choosing-the-environment">#</a></h3>
<p>Debug builds use <code>development</code> and release builds use <code>production</code>. To build another environment:</p>
<div class="table-wrap"><table>
<thead>
<tr>
<th>Platform</th>
<th>How</th>
</tr>

<tr>

</tr>
<tr>

<td><code>./gradlew -PappEnvironment=staging</code>. The value becomes <code>BuildConfig.APP_ENVIRONMENT</code>.</td>

</tbody>

<p>An unknown environment name fails when the app starts, with a message listing the valid names.</p>
<h3 id="secrets">Secrets<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#secrets">#</a></h3>
<p>Secrets are declared by name. Their values never go in <code>contracts/</code>.</p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="json"><code><span class="line"><span style="color:#686664">{</span></span>
<span class="line"><span style="color:#686664">  "</span><span style="color:#0B0B0B">secrets</span><span style="color:#686664">"</span><span style="color:#686664">:</span><span style="color:#686664"> {</span></span>
<span class="line"><span style="color:#686664">    "</span><span style="color:#0B0B0B">mapsApiKey</span><span style="color:#686664">"</span><span style="color:#686664">:</span><span style="color:#686664"> {</span><span style="color:#686664"> "</span><span style="color:#0B0B0B">type</span><span style="color:#686664">"</span><span style="color:#686664">:</span><span style="color:#9F0310"> "string"</span><span style="color:#686664">,</span><span style="color:#686664"> "</span><span style="color:#0B0B0B">description</span><span style="color:#686664">"</span><span style="color:#686664">:</span><span style="color:#9F0310"> "Google Maps SDK key"</span><span style="color:#686664"> }</span></span>
<span class="line"><span style="color:#686664">  }</span></span>
<span class="line"><span style="color:#686664">}</span></span></code></pre>
<p>A secret's name becomes a key in <code>.env</code> at the project root: <code>mapsApiKey</code> is <code>MAPS_API_KEY</code>. <code>type</code> must be <code>"string"</code>. A secret with a <code>value</code> field is rejected, so a real key can't be committed by mistake. There is one value per key, not one per environment.</p>
<p><code>make gen</code> reads <code>.env</code> and generates:</p>
<div class="table-wrap"><table>
<thead>
<tr>
<th>Platform</th>
<th>Generated</th>
<th>Committed</th>
</tr>
</thead>
<tbody>
<tr>
<td>iOS</td>
<td><code>AppSecrets.mapsApiKey</code>, with the value written into <code>App/Generated/AppSecrets.swift</code></td>
<td>No, it is git-ignored</td>
</tr>
<tr>
<td>Android</td>
<td><code>AppSecrets.mapsApiKey</code>, with the value written into <code>generated/AppSecrets.kt</code></td>
<td>No, it is git-ignored</td>
</tr>
<tr>
<td>Web</td>
<td><code>AppSecrets.mapsApiKey</code> from <code>src/generated/secrets.server.ts</code>, which reads <code>process.env.MAPS_API_KEY</code> on the server</td>
<td>Yes, it holds names only</td>
</tr>
</tbody>
</table></div>
<p>The web module throws if it runs in the browser. Use it only in server functions and API routes.</p>
<p><code>make gen</code> also writes <code>.env.example</code>, which lists every key and is committed. Copy it to <code>.env</code> and fill it in. If <code>.env</code> is missing a key, the value is empty and <code>make gen</code> prints a warning, so a fresh clone still builds. <code>make doctor</code> reports the same thing.</p>
<p>Mobile apps embed the values they are built with, so treat the built app as readable by anyone who has it. Keep keys that must stay private on a server.</p>
