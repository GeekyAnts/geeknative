<p><strong>Names</strong> are camelCase letters and digits starting lowercase, and can't be reserved words in Swift, Kotlin or TypeScript (like <code>default</code> or <code>class</code>).</p>
<p><strong>Colors</strong> are <code>#RRGGBB</code> or <code>#RRGGBBAA</code>. <code>dark</code> is optional and defaults to <code>light</code>. These colors are required: <code>background</code>, <code>onBackground</code>, <code>surface</code>, <code>onSurface</code>, <code>surfaceVariant</code>, <code>onSurfaceVariant</code>, <code>primary</code>, <code>onPrimary</code>, <code>outline</code>, <code>error</code> and <code>onError</code>. You can add more.</p>
<p><strong>Spacing, radius, icon and size</strong> values are numbers of points (iOS), dp (Android) or pixels (web). <code>size</code> is optional and holds fixed sizes of things, like touch targets: its names can't repeat a spacing name or start with <code>icon</code>, because on the web they all share Tailwind's spacing scale. A radius of 9999 or more is fully rounded on the web. Icon sizes are the sizes icons are drawn at in content.</p>

<tr>
<th>Rule</th>
<th>Detail</th>

<tbody>
<tr>
<td>Keys</td>
<td>Dot-separated camelCase words: <code>settings.appearance.title</code>. Two keys can't map to the same name. <code>app.name</code> isn't allowed (the name comes from <code>app.json</code>).</td>

<p>A secret's name becomes a key in <code>.env</code> at the project root: <code>mapsApiKey</code> is <code>MAPS_API_KEY</code>. <code>type</code> must be <code>"string"</code>. A secret with a <code>value</code> field is rejected, so a real key can't be committed by mistake. There is one value per key, not one per environment.</p>
<p><code>make gen</code> reads <code>.env</code> and generates:</p>

<p>The web module throws if it runs in the browser. Use it only in server functions and API routes.</p>
<p><code>make gen</code> also writes <code>.env.example</code>, which lists every key and is committed. Copy it to <code>.env</code> and fill it in. If <code>.env</code> is missing a key, the value is empty and <code>make gen</code> prints a warning, so a fresh clone still builds. <code>make doctor</code> reports the same thing.</p>
<p>Mobile apps embed the values they are built with, so treat the built app as readable by anyone who has it. Keep keys that must stay private on a server.</p>
