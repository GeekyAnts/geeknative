<h2 id="working-on-the-template">Working on the template<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#working-on-the-template">#</a></h2>
<p><code>template/</code> is a real project. Build it in place:</p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="shell"><code><span class="line"><span style="color:#0B0B0B;font-weight:bold">cd</span><span style="color:#0B0B0B"> template</span></span>
<span class="line"><span style="color:#0B0B0B;font-weight:bold">npm</span><span style="color:#0B0B0B"> install</span></span>
<span class="line"><span style="color:#0B0B0B;font-weight:bold">make</span><span style="color:#0B0B0B"> check</span></span></code></pre>
<p>Generated code is committed in <code>template/</code>. After changing a contract in <code>template/contracts/</code> or a generator in <code>packages/geeknative/src/codegen/</code>, regenerate and commit the output:</p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="shell"><code><span class="line"><span style="color:#0B0B0B;font-weight:bold">cd</span><span style="color:#0B0B0B"> template</span></span>
<span class="line"><span style="color:#0B0B0B;font-weight:bold">node</span><span style="color:#0B0B0B"> ../packages/geeknative/bin/geeknative.js</span><span style="color:#0B0B0B"> gen</span></span></code></pre>
<p>Codegen output must be deterministic.</p>
<p>Some template files belong to the framework (the files listed in <code>packages/geeknative/src/lib/managed.js</code>, and the <code>geeknative:begin</code> and <code>geeknative:end</code> blocks in AGENTS.md and CLAUDE.md files). Upgrades will replace them in existing projects. Everything else in <code>template/</code> is copied once at create time and then belongs to the project, so changes there only reach new projects.</p>
<p>Template files named <code>_gitignore</code> become <code>.gitignore</code> when a project is created, because npm drops real <code>.gitignore</code> files from published packages.</p>

<p>CI (<code>.github/workflows/ci.yml</code>) runs on every push and pull request: the CLI test suite, a smoke test that creates a project and checks its contracts and web app, and the template's web and Android checks on Ubuntu and iOS checks on macOS. <code>.github/workflows/docs.yml</code> builds this site and deploys it to GitHub Pages.</p>
<h2 id="documentation">Documentation<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#documentation">#</a></h2>
<p>The docs live in <code>website/content/docs/</code> as Markdown. Update them in the same change as the behavior they describe.</p>
<pre class="shiki geeknative" style="background-color:#f5f4f2;color:#0b0b0b" tabindex="0" data-language="shell"><code><span class="line"><span style="color:#0B0B0B;font-weight:bold">cd</span><span style="color:#0B0B0B"> website</span></span>
<span class="line"><span style="color:#0B0B0B;font-weight:bold">npm</span><span style="color:#0B0B0B"> install</span></span>
<span class="line"><span style="color:#0B0B0B;font-weight:bold">npm</span><span style="color:#0B0B0B"> run</span><span style="color:#0B0B0B"> dev</span></span></code></pre>
<p><code>npm run build</code> exports the site to <code>out/</code> and indexes it for search; <code>npm run check-links</code> then fails on any broken internal link.</p>
