22:T8d1,<p>geeknative 0.1.0 is the foundation: three apps that build and test from the command line, contracts and codegen, the agent instructions, Claude Code integration, and the <code>create</code>, <code>gen</code>, <code>check</code>, <code>doctor</code>, <code>parity</code> and <code>run</code> commands.</p>

<h2 id="upgrades-and-agent-evaluation">Upgrades and agent evaluation<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#upgrades-and-agent-evaluation">#</a></h2>
<ul>
<li><strong><code>geeknative upgrade</code>.</strong> Replace framework files that you haven't changed, three-way merge the ones you have, and list conflicts, using the hashes in <code>.geeknative/lock.json</code>. See <a href="/geeknative/docs/concepts/file-ownership/">File ownership</a>.</li>
<li><strong>Migrations.</strong> Scripted migrations for mechanical changes (such as a new spec format), and written migrations an agent applies across all three apps for changes that need judgment.</li>
<li><strong>Agent evaluation.</strong> A set of real prompts (a feature, a design change, a bug, a platform-only tweak) run through several agents, used to tune AGENTS.md and the playbooks wherever agents go wrong.</li>
</ul>
<h2 id="visual-and-end-to-end-parity">Visual and end-to-end parity<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#visual-and-end-to-end-parity">#</a></h2>
<ul>
<li><strong>UI tests</strong> on iOS and Android, so screen-level acceptance criteria (like the starter Home screen's) are covered on every platform.</li>
<li><strong>Screenshots</strong> of each screen from all three apps, side by side, for visual review.</li>
<li><strong>Shared end-to-end flows</strong> with Maestro for iOS and Android, and Playwright for the web.</li>
<li><strong>CI for generated projects.</strong></li>
</ul>
<h2 id="more">More<a class="heading-anchor" aria-hidden="true" tabindex="-1" href="#more">#</a></h2>

<li><strong>Backends.</strong> An API contract in <code>contracts/</code>, generated clients, and repository implementations that call it.</li>
<li><strong>Custom fonts</strong> in design tokens.</li>
<li><strong>Windows</strong> support for the Android and web apps.</li>
