# Product

## In one sentence

Taskflow is a calm, fast task manager: capture tasks, set a priority and due date, filter to what matters, and tick things off, on iPhone, Android and the web, all backed by one server.

## Who it's for

Individuals and small-team members who juggle a few dozen work tasks a week and want a focused list they can trust on every device, without the weight of a project-management suite.

## Platforms

| Platform | Built with | Minimum |
|---|---|---|
| iOS | SwiftUI | iOS 17 |
| Android | Kotlin, Jetpack Compose | Android 7.0 (API 24) |
| Web | React, TanStack Start | Safari 16.4, Chrome 111, Firefox 128 |
| Backend | Node.js, Express, SQLite (`node:sqlite`) | Node 22.13 |

**Consistency:** `strict` in `contracts/app.json`. Every feature ships on all three platforms with the same screens and behavior; controls and navigation chrome stay native.

**Data:** every app reads and writes tasks through the Taskflow REST API described in `contracts/api.json` (OpenAPI 3.1), with clients generated by `make gen`. The server lives in `backend/`. Only the appearance setting is stored on the device.

## Glossary

Domain terms, defined once. Code uses these exact names on every platform.

| Term | Meaning |
|---|---|
| Task | Something to do. API model `TaskItem` (named so it doesn't shadow Swift's `Task`): id, title, notes, status, priority, optional due date, created and updated timestamps |
| Status | `todo` (To do), `inProgress` (In progress) or `done` (Done). Code: `TaskStatus` |
| Open task | A task whose status is To do or In progress |
| Priority | `low`, `medium` or `high`. Code: `TaskPriority` |
| Due date | An optional calendar date (`YYYY-MM-DD`), with no time or time zone |
| Overdue | An open task whose due date is before today's local date |
| Filter | The status and priority the Tasks list is narrowed to. Code: `TaskFilter` |

## Out of scope

- Accounts, sign-in and sharing: version one is single-user, with one shared server.
- Offline editing: the apps need the server to load and save tasks.
- Subtasks, tags, attachments, reminders and recurring tasks.
- Search (status and priority filters only).
